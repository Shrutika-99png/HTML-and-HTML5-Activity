HTML and HTML5

Understanding the difference through examples

What are HTML and HTML5?

HTML is the markup language used to structure web pages. HTML5 is the modern version of HTML, with semantic elements, built-in multimedia support, improved forms and browser APIs.

Comparison

FeatureOlder HTMLHTML5
DoctypeLong declarationSimple <!DOCTYPE html>
StructureMostly generic div elementsheader, nav, main, section, article, footer
MediaOften required pluginsaudio and video elements
GraphicsLimited native supportcanvas and SVG support
FormsBasic input typesemail, date, number, range and more
StorageLimited browser-side optionsWeb Storage and other browser APIs
